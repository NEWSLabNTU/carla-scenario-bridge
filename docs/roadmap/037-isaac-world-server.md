# Phase 037: Isaac World Server and `IsaacBackend`

SSv2 scenarios run on Isaac Sim: an Isaac-side world server owns the stage and the loop, and
csb's `IsaacBackend` drives it over a small local protocol, one round trip per frame. No
Autoware yet: the ego is driven by SSv2 (`managed_ego`-style puppeteering) or a scripted
controller, so the world, entities, clock and contacts can be verified on their own.

**Source**: user direction 2026-10-16; [design/simulator-backends.md](../design/simulator-backends.md).
**Depends on**: [035](035-backend-seam.md) (trait), [036](036-isaac-bringup.md) (install,
step model).
**Feeds**: [038](038-isaac-vehicle-bridge.md), [040](040-ntu-offroad-field.md).

## Design

- **Package** `src/csb_isaac/` (Python, run with Isaac's `python.sh`): `world_server.py`
  (the app), `world.py` (stage and entity management), `protocol.py` (generated from
  `proto/csb_world.proto`), `assets/` (entity USDs by subtype), tests runnable without Isaac
  where possible.
- **Protocol** `proto/csb_world.proto`, ZMQ REQ/REP on `tcp://127.0.0.1:<world_port>`:
  `Hello{protocol_version, isaac_version}`, `LoadWorld{usd, map_origin}`,
  `Spawn{name, kind, subtype, box, pose, puppeteered, ego}` → `{handle}`, `Despawn{handle}`,
  `Step{poses[], substeps, dt}` → `{sim_time, frame, states[], contacts[]}`,
  `Shutdown`. A version mismatch is refused with both versions in the message (as csb does
  for CARLA).
- **Loop**: the server blocks on the socket between frames; `Step` applies poses, advances
  `substeps` physics steps of `dt` and renders once, then replies. Sim time is Isaac's and
  monotonic across worlds, so `IsaacBackend` reports it as is: the episode clock (015) and
  its epoch marker exist for CARLA's per-episode reset and acb, and stay in `CarlaBackend`.
  `UpdateEntityStatus` sends the poses and reads the states; `UpdateFrame` sends `Step`
  (the trait's two calls per frame, 035 "As built").
- **Entities**: puppeteered NPCs are kinematic rigid bodies with colliders sized to the
  declared box (asset scaled; residual reported as in 022); pedestrians and misc objects
  likewise. Despawn removes the prim; `Initialize`/episode change resets the stage to the
  loaded world (the Isaac counterpart of 007's teardown).
- **Ego for this phase**: a kinematic body moved by SSv2 or by a scripted speed profile;
  the PhysX vehicle arrives in 038.
- **Contacts**: PhysX contact reports on the ego, returned per step, for csb's contact report
  (021) and gap trace (024). Both live in `backend/carla/` after 035; this phase lifts them
  into shared modules fed by either backend, the CARLA side unchanged.
- **Signals and weather**: `Unsupported` (honest failure, 006).
- **Test world**: a flat ground plane with a road texture and a matching small Lanelet2 map
  (a straight and a loop), generated by a script so it is reproducible; scenario dir and map
  dir follow 017's layout.
- **Launch**: `simulation.launch.xml backend:=isaac` starts csb and expects the world server;
  `ros2 run csb_isaac world_server` (wrapping `python.sh`) starts the server, headless by
  default, `display:=:N` for VNC.

## Steps

- [ ] `csb_world.proto` and both ends (prost in csb, protobuf in Python).
- [ ] World server: load, spawn, despawn, step, reset; unit tests on the protocol layer.
- [ ] `IsaacBackend` implementing `SimBackend`; coordinator unit tests on the fake backend
      still pass; `backend:=isaac` accepted at startup (035 refuses it).
- [ ] Gap trace and contact reports out of `backend/carla/` into shared modules (035 left
      them there), the CARLA trace unchanged in content.
- [ ] Test world + Lanelet2 map generator; starter scenarios that need no traffic lights
      adapted to it (`csb_examples/isaac/`).
- [ ] Gap trace on Isaac: SSv2 vs Isaac pose per frame within 1 mm for puppeteered NPCs.
- [ ] Frame budget: csb + server round trip with 20 NPCs, p95.

## Acceptance

- A starter scenario with NPCs runs to SSv2's verdict on Isaac, headless, three times in a row
  unattended, with the same verdict and the same contact count each time.
- Puppeteered NPC poses in Isaac match SSv2's within 1 mm (gap oracle).
- Round-trip cost with 20 NPCs and no sensors: p95 under 5 ms.
